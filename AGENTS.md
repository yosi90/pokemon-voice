# AGENTS.md

## Contexto del proyecto

Este proyecto es un juego web sobre descubrir la Pokedex mediante comandos de voz. La experiencia principal consiste en decir nombres de Pokemon para ir revelando entradas, aunque tambien existe un fallback de texto para poder jugar sin microfono o cuando el reconocimiento de voz no funcione correctamente.

El juego incluye logros, progresion de descubrimiento y modos de juego especiales. Cualquier cambio debe respetar esa idea central: una Pokedex jugable, con interacciones claras, feedback inmediato y una presentacion inspirada en Pokemon.

## Guia de desarrollo

Para el desarrollo del proyecto se mantiene una guia interna en:

`docs/codex/directrices-desarrollo.md`

Antes de realizar cambios relevantes, revisa esa guia y sigue sus directrices. Si una tarea introduce una nueva convencion importante, documentala alli o en el roadmap correspondiente.

## Roadmaps

Los desarrollos largos deben documentarse en `docs/roadmaps/`. Cada roadmap debe servir para recordar el trabajo hecho, lo pendiente y el estado actual del desarrollo.

Los roadmaps deben incluir listas de checks y actualizarse a medida que se completan tareas. Cuando un roadmap este terminado, renombra el archivo poniendo `[Finalizado]` delante del nombre.
